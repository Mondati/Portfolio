# Technology icons

`technologies.svg` contains unmodified icon paths from Simple Icons 13.21.0,
repackaged as SVG symbols with inherited color.

Source: https://cdn.jsdelivr.net/npm/simple-icons@13.21.0/icons/
Project and CC0 license: https://github.com/simple-icons/simple-icons/tree/13.21.0

Icons: springboot, springsecurity, spring, hibernate, apachemaven,
swagger, junit5, postman, c, cplusplus.
Spring Cloud and Spring Data JPA use the shared Spring ecosystem logo.
SQL Server uses microsoftsqlserver from Simple Icons 11.15.0 (CC0):
https://cdn.jsdelivr.net/npm/simple-icons@11.15.0/icons/microsoftsqlserver.svg
Microservices and RUP use the existing Font Awesome diagram-project and
arrows-rotate pictograms respectively, rather than product brand logos.
Brand names and logos remain the property of their respective owners.
MySQL uses the dolphin-only SVG from Devicon v2.17.0, with its fill changed
to currentColor: https://github.com/devicons/devicon/blob/v2.17.0/icons/mysql/mysql-original.svg
Devicon license: https://github.com/devicons/devicon/blob/v2.17.0/LICENSE
The other existing brand icons and methodology pictograms use the existing
Font Awesome stylesheet; no additional runtime dependency is introduced.
